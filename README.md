# Warwick Ready

A mobile-first, student-friendly starting point for getting ready to move to Warwick.

## V1
- Responsive/mobile-first layout
- Thumb-friendly bottom navigation on mobile
- Journey roadmap
- Persistent checklist using localStorage
- Official Warwick resource links
- Reduced-motion support
- No framework or build step required

## Run locally
Open `index.html` in a browser.
